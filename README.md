# tv-casa

Lista IPTV arrumada por temas, com guia de TV em português.
Atualiza-se sozinha de 6 em 6 horas (GitHub Actions).

## Endereços para o TiviMate

- Lista: `https://raw.githubusercontent.com/AppcreatorPT/tv-casa/main/tv.m3u`
- Guia: `https://raw.githubusercontent.com/AppcreatorPT/tv-casa/main/epg.xml.gz`

## Grupos

Generalistas · Notícias · Desporto · Filmes · Séries · Anime · Infantil · Documentários · Música · Brasil

## Fontes

- [iptv-org](https://github.com/iptv-org/iptv): canais portugueses públicos.
- Pluto TV Brasil: canais grátis em português.
- [epgshare01](https://epgshare01.online): guia dos canais portugueses.

Os canais mortos saem da lista na atualização seguinte.
Para mudar grupos ou canais, edite `gerar.py`.
